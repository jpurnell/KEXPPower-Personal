This is an app that uses a forked version of the KEXP Power framework to display a live version of the KEXP Playlist, to listen to the live stream, and (eventually) to add songs directly to a dedicated KEXP Apple Music playlist. It is intended to be faster and more user-friendly than the existing KEXP app. These features are to be integrated with iOS, macOS, and visionOS. Ideally, this would also extend to CarPlay.
